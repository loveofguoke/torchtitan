## 维护规则

1. 主计划中的目标和基线发生变化时，必须记录变更日期、原因和责任人。
2. 每周至少更新一次“执行跟踪”，附提交、日志、报告或性能数据链接。
3. “代码完成”不等同于“已验收”；只有满足验收标准并附证据后才标记为
   “已验收”。
4. GPU、NPU 精度比较必须记录模型配置、权重、数据、随机种子、步数、精度、
   loss 计算方法和容差。
5. 性能比较必须记录硬件、卡数、软件版本、并行策略、序列长度、batch size、
   warmup、统计窗口和有效吞吐口径。
6. 尚未量化的指标应明确标记为“尚未冻结”，不得用临时数字代替正式验收阈值。
